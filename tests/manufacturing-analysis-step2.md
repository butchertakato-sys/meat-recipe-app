# 製造実績・分析 UI 検証（2026-10-13）

表示順：絞り込み → 製造記録一覧 → 商品別集計表 → 折りたたみの集計サマリー・前月/前年同月比較。
月別棒グラフ・歩留まり推移グラフ、その描画関数と専用スタイルを削除。
月別集計の純粋関数は既存集計回帰テスト用に維持。期間比較・加重歩留まり・数量区分・構成比計算は変更なし。

`npm test` は全単体テストとsync-integration、record-observation-integration、history-startup-integration、manufacturing-analysis-integrationを実行する。
ブラウザは隔離origin / 新規context / モックRESTのみ。本番Supabaseに接続しない。
新しい分析専用CSSも正しいtext/css MIMEで配信して実表示を検証する。

| 必須項目 | 検証 |
| --- | --- |
| 1〜2 表を優先 | 見出し順、表・カードの画面上の位置、一覧が初期viewportの上部にあること |
| 3〜4 グラフ削除 | 全端末幅でSVG/グラフ要素なし、描画関数・専用スタイルの参照調査 |
| 5 期間比較 | 折りたたみ展開、前月/前年同月の基準月・値・ポイント差、並べ替え時DOM維持 |
| 6〜7 全項目 | 一覧10列・集計表7列、仕込み日・保存時180g維持、総計行 |
| 8 絞り込み・順序 | 商品・製造区分・期間指定、日付順、空期間、プリセット時日付欄非表示 |
| 9〜10 構成比・歩留まり | 完成重量68/16/16%、59.0/20.5/20.5%、総計55.6%、部分期間46.0% |
| 11 数量単位 | パック/本の分離、ハーブ通常/イベント/峠、ジビエ燻製/燻製なし |
| 12〜15 実レイアウト | 375×812、390×844、768×1024、820×1180、1024×768、1366×1024 |
| 12〜15 幅・操作 | 本文/ヘッダーの利用可能幅、絞り込み2列/4列、白カード、フォント13px以上、44px以上のボタン |
| 12〜15 表スクロール | 必要幅のみ横スクロール、固定見出し・商品名、テキストRangeが列からはみ出さない、ページ全体の横はみ出しなし |
| 16 詳細遷移 | 正しいIDで詳細表示、共有700px幅へ復元 |
| 17 保存・同期回帰 | 既存3本の統合テスト全実行、削除済み除外、同一LOT別ID、オフライン・読み取り専用 |
| 18 他画面の不変 | 分析前後でホームと製造入力のDOM/幅/主要computed stylesを比較、既存保護関数のハッシュ検証 |

CSSは `#manufacturingAnalysis` と、その存在に限定した `:has` セレクターで適用。
iPad・iPhone Safari 15.4以降の `:has` 対応を前提とする。旧ブラウザでは共通幅のまま表スクロールを利用可能。
商品別の正式な歩留まり警告基準は現行コードにないため、警告色を追加していない。
構成比・総計・個別保存歩留まり・重量・数量の数値を変更していない。
既存CSV出力は「製造記録 → CSV出力」で維持。

実機で残る確認：Safariのタッチ横スクロール・固定列、端末回転、ホーム画面起動時の既存キャッシュ更新。
参考画像は今回の会話・リポジトリにないため、指示された配色・案4の構成を基準に設計。

最終検証：単体86件 PASS / FAIL 0、ブラウザ統合4本PASS、`git diff --check` PASS。
375pxと1366pxの生成スクリーンショットを目視確認。文字の重なり・ページ外へのはみ出しなし。
履歴統合テストは同期時刻のIndexedDB表示完了を待ってからDOMを比較し、非同期読み込み中の差を再描画と誤判定しないよう修正。
